# Pure Markdown

This route is a `page.md` file, same markdown pipeline as MDZX, without ZX embeds.

## Why `.md`?

Use it when the page is documentation-only and you do not need components or `{expressions}`.

## Formatting

**Bold**, *italic*, ~~strike~~, and `inline code`.

## Lists

- One
- Two

1. First
2. Second

> Quotes work too.

```zig
const pure = true;
```
